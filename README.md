# GBSHS_Exhibition — 여행의 조각

2026 해외 이공계 체험학습 온라인 전시관. 상단 검색, 전체 작품·우수작 선택 버튼과 사진과 글, 시화, 음악, 그림·만화, 카드뉴스, 숏폼 영상, 기타의 일곱 작품 종류 필터를 제공한다. 검색과 종류 필터는 선택한 전시 목록에 함께 적용하며, 작품을 닫아도 선택한 목록을 유지한다.

## 코드와 제출 자료 분리

학생·작품 목록은 `private/catalog.json`, 응답 대조와 보류 기록은 `private/submission-audit.json`에 별도로 보관한다. 두 파일은 공개 저장소에 포함하지 않는다. `dist/catalog.js`도 빌드 과정에서만 생성하며 Git에서 제외한다.

감상용 데이터에는 작성자 라벨과 감상에 필요한 링크만 넣는다. 원본 파일명, 응답 시각, 보류 내역은 별도 자료에 남긴다. 생성된 웹페이지에는 전시용 정보가 포함되므로 별도 HTML 파일을 공개 저장소에 커밋하지 않는다.

## 실행 및 미리보기

Node.js가 필요하며 별도 패키지 설치는 없다. 별도로 보관한 자료에서 `catalog.json`을 복원해 `private/catalog.json`에 놓는다.

```sh
node server.mjs
```

http://127.0.0.1:4175 에서 전시관을 연다. 서버는 `dist/`만 제공하며 원본 자료 폴더를 제공하지 않는다.

```sh
node build-preview.mjs
```

서버 없이 열 수 있는 `outputs/exhibition-draft.html`을 만든다. 파일을 열어도 작품 감상에는 인터넷 연결과 원본 Drive 접근 권한이 필요하다. 코드 구문, HTML 참조, 중복 ID, CSS 괄호와 외부 코드 의존성도 검사한다.

## 작품 및 우수작

한 번만 제출한 학번의 작품을 사용하고, 여러 제출 행이 있는 학번은 전체 보류한다. 학생 이름·학번과 유형은 제출표를 따른다. 확인하지 않은 작품 제목을 지어 붙이지 않고 작성자와 유형으로 표시한다.

우수작은 제출표에 직접 칠한 셀 배경색을 기준으로 지정한다. 제목 행과 자동 교차 회색 배경은 선정 표시로 보지 않는다. 우수작도 중복 보류 원칙을 적용한다. 서로 다른 색에 별도의 등급 의미를 부여하지 않는다.

썸네일은 지연 로딩하며, 작품을 선택할 때만 Drive 미리보기를 연다. 닫거나 다음 작품으로 이동하면 기존 재생 화면을 제거한다. 이미지가 열리지 않으면 종류 아이콘과 원본 보기 기능을 유지한다.

## 검증

```sh
node tests/awards.test.mjs
```

일반 탐색과 우수작 탐색, 링크 복원, 선정 의견 및 배지를 검사한다. 별도 자료가 있으면 실제 작품 수, 수동 색 표시, 중복 보류, 일곱 유형, 미디어 지연 로딩과 종료도 검사한다.
